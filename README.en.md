## About the project

I collect visual novel walkthroughs drawn as flowcharts. The goal is not just a list of choices, but a convenient guide: you can see where branches split, how to reach the ending you want, and which scenes can be skipped.

Right now the catalog contains only my own work. But I am considering expanding it with other people's charts of the same kind — if you have an opinion, write in [Discussions](https://github.com/FLS76/flowchart-guide-visual-novels.github.io/discussions).

## What's on the site

| Section | Description |
|---|---|
| **Completed** | Visual novels with finished flowcharts |
| **Planned** | Visual novels whose charts the author wants to make |
| **No flowchart needed** | Kinetic visual novels and novels that already contain a complete flowchart in-game |

Every chart page includes:
- A full-screen flowchart with zoom and pan
- Information: author, language, version
- The author's comment
- Theme (dark / light) and language (RU / EN) switching

## How to use

1. Open the [site](https://fls76.github.io/flowchart-guide-visual-novels.github.io) or the local `index.html`.
2. Choose the **Completed** tab.
3. Click the poster of the novel whose flowchart you want to see.
4. Open the flowchart — click the image to view it full screen.

**Viewer controls:**
- **Mouse wheel** — zoom (anchored to the cursor)
- **Dragging** — pan
- **Double click** — toggle between “fit” and actual size
- **← / →** — next / previous flowchart
- **Esc** — close
- **The `?` button** — the full list of hotkeys

All hotkeys:

| Key | Action |
|---|---|
| `Esc` | close the viewer |
| `+` / `−` | zoom |
| `0` | fit to screen |
| `1` | actual size (1:1) |
| `W` / `H` | fit to width / fit to height |
| `M` | minimap |
| `F` | fullscreen |
| `←` / `→` | previous / next flowchart |
