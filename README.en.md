# Flowchart Guide — Visual Novels

**Visual novel walkthroughs as flowcharts.**

Not a list of choices, but a guide: where branches split, how to reach the ending you want, which scenes can be skipped.

## What's inside

- **22 visual novels** with finished flowcharts.
- **14 visual novels** in progress — the charts are still being made.
- **14 visual novels** that need no chart: kinetic ones, or ones that already ship a complete flowchart in-game.
- Dark and light themes, Russian and English — on every page.
- A chart viewer: zoom, pan, minimap, switching between charts.

## How to use

Open the [site](https://flowchart-guide-visual-novels.github.io), pick the “Completed” tab, click a novel cover, then click the chart to open it in the viewer.

| Key | Action |
|---|---|
| `Esc` | close the viewer |
| `+` / `−` | zoom (mouse wheel zooms toward the cursor) |
| `0` | fit to screen |
| `1` | actual size (1:1) |
| `W` / `H` | fit to width / fit to height |
| `M` | minimap |
| `F` | fullscreen |
| `←` / `→` | previous / next chart |

Dragging with the mouse pans the chart, a double click toggles between “fit” and actual size, and the `?` button in the corner shows this table.
