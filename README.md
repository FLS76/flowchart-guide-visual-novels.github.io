# Руководства для визуальных новелл в виде блок-схем

Статический каталог руководств по прохождению визуальных новелл в виде блок-схем. Публикуется на GitHub Pages: `flowchart-guide-visual-novels.github.io`. Название сайта по-английски — `Flowchart guide visual novels` (совпадает с адресом).

## Структура

```
Flowchart guide visual novels/
├── index.html              # Главная: «О проекте», «Сделано», «В планах», «Не требуют схем»
├── style.css               # Стили главной
├── script.js               # Переключение вкладок и запоминание последней вкладки
├── settings.js             # Глобальные настройки (тема, язык) — единый источник истины
├── theme.js                # Переключатель темы
├── i18n.js                 # Словарь RU/EN + кнопка языка
├── schema-img.js           # Заглушка если schema.png не найден
├── schema-viewer.js        # Просмотровик схем (зум, пан, навигация)
├── robots.txt
├── sitemap.xml
├── assets/
│   ├── favicon.png
│   ├── posters/            # 36 постеров новелл
│   └── schemas/            # 23 PNG-файла блок-схем
└── novels/
    ├── style.css           # Общие стили страниц новелл и схем
    └── <slug>/
        ├── index.html      # Постер слева, название и информация справа
        └── schemaN/
            └── index.html  # Страница блок-схемы
```

## Что уже есть

- 22 новеллы со схемами и 14 новелл, которым схемы не нужны.
- Локальные постеры: изменения на VNDB не влияют на сайт.
- Тёмная тема по умолчанию, светлая — тёплая солнечная.
- Переключение языка RU/EN на всех страницах.
- Просмотровик блок-схем: зум колёсиком, панорама перетаскиванием, навигация ← →.
- Адаптивная вёрстка для десктопа и мобильных.
- Переключение вкладок без перезагрузки, последняя вкладка запоминается.

## Как использовать

1. Открыть `index.html` или опубликованную версию сайта.
2. Выбрать вкладку «Сделано».
3. Нажать на постер новеллы.
4. Открыть нужную блок-схему.
