# Flowchart Guide — Visual Novels

**Прохождения визуальных новелл в виде блок-схем.**

Не сводка выборов, а путеводитель: где ответвляются ветки, как дойти до нужной концовки, какие сцены можно пропустить.

## Что внутри

- **22 новеллы** с готовыми блок-схемами.
- **14 новелл** в планах — схемы ещё создаются.
- **14 новелл**, где схема не нужна: кинетические или с готовой схемой внутри игры.
- Тёмная и светлая темы, русский и английский — на всех страницах.
- Просмотрщик схем: масштаб, панорама, мини-карта, переключение между схемами.

## Как пользоваться

Откройте [сайт](https://flowchart-guide-visual-novels.github.io), вкладка «Сделано», нажмите на постер новеллы и кликните по схеме — она откроется в просмотрщике.

| Клавиша | Действие |
|---|---|
| `Esc` | закрыть просмотрщик |
| `+` / `−` | масштаб (колесо мыши — с привязкой к курсору) |
| `0` | вписать целиком |
| `1` | реальный размер (1:1) |
| `W` / `H` | по ширине / по высоте |
| `M` | мини-карта |
| `F` | полноэкранный режим |
| `←` / `→` | предыдущая / следующая схема |

Перетаскивание мышью двигает схему, двойной клик переключает «вписать» и реальный размер, кнопка `?` в углу показывает эту таблицу.
