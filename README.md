# Flowchart Guide — Visual Novels

Прохождения визуальных новелл в виде блок-схем. Статический сайт, опубликованный на GitHub Pages.

**Сайт:** [flowchart-guide-visual-novels.github.io](https://flowchart-guide-visual-novels.github.io)

---

## О проекте

Я собираю в одном каталоге прохождения визуальных новелл, нарисованные в виде блок-схем. Цель — не просто сводка выборов, а удобный путеводитель: видно, где ответвляются ветки, как дойти до нужной концовки, какие сцены можно пропустить.

Сейчас в каталоге только мои работы. Но я рассматриваю возможность добавить и чужие схемы того же типа — если у вас есть мнение, напишите в [Discussions](https://github.com/FLS76/flowchart-guide-visual-novels.github.io/discussions).

---

## Что на сайте

| Раздел | Описание |
|---|---|
| **Сделано** | 22 новеллы с готовыми блок-схемами |
| **В планах** | Новеллы, для которых схемы ещё создаются |
| **Не требуют схем** | 14 кинетических новелл и прохождений, где схема уже внутри игры |

Каждая страница схем включает:
- Полноэкранную блок-схему с зумом и панорамой
- Информацию: автор, язык, версия
- Комментарий автора
- Переключение темы (тёмная / светлая) и языка (RU / EN)

## Как пользоваться

1. Откройте [сайт](https://flowchart-guide-visual-novels.github.io) или локальный `index.html`.
2. Выберите вкладку **«Сделано»**.
3. Нажмите на постер новеллы.
4. Откройте нужную блок-схему — кликните по изображению для просмотра в полном размере.

**Управление просмотровиком:**
- **Колёсико** — масштаб
- **Перетаскивание** — панорама
- **← / →** — следующая / предыдущая схема
- **Esc** — закрыть
- **⊡** — подогнать по размеру
