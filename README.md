# Прохождения визуальных новелл в виде блок-схем

Статический каталог руководств по прохождению визуальных новелл в виде блок-схем. Публикуется на GitHub Pages: `flowchart-guide-visual-novels.github.io`.

## Структура

```
Flowchart guide visual novels/
├── index.html              # Главная: «О проекте», «Сделано», «В планах», «Не требуют схем»
├── style.css               # Стили главной
├── script.js               # Переключение вкладок и запоминание последней вкладки
├── robots.txt
├── sitemap.xml             # 43 адреса
├── assets/
│   ├── favicon.png
│   └── posters/            # 34 локальных постера (20 + 14)
└── novels/
    ├── style.css           # Общие стили страниц новелл и схем
    └── <slug>/
        ├── index.html      # Постер слева, название и информация справа
        └── schemaN/
            └── index.html  # Страница блок-схемы
```

## Что уже есть

- 20 новелл со схемами и 14 новелл, которым схемы не нужны.
- Локальные постеры: изменения на VNDB не влияют на сайт.
- Адаптивная вёрстка для десктопа и мобильных.
- Переключение вкладок без перезагрузки, последняя вкладка запоминается.
- Раздел «О проекте» объясняет, что на сайте могут появляться и чужие работы при указании авторства.

## Чего не хватает

- Файлы `schema.png` для 22 страниц схем. Без них на страницах схем отображается битая картинка.

## Источник

Все блок-схемы взяты с блога автора (проверщик) на squarefaction.com:
https://ru.squarefaction.com/member/u108729/blog/21498-prohozhdeniya-shemy-vizualnyh-novell

## Как использовать

1. Открыть `index.html` или опубликованную версию сайта.
2. Выбрать вкладку «Сделано».
3. Нажать на постер новеллы.
4. Открыть нужную блок-схему.
