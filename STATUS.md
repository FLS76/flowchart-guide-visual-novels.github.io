## Сейчас

- **Сайт опубликован:** https://fls76.github.io/flowchart-guide-visual-novels.github.io/
  - Репозиторий: `FLS76/flowchart-guide-visual-novels.github.io` (public), ветка `master`.
  - GitHub Pages включён, сборка — через workflow `.github/workflows/pages.yml` (push → build → deploy).
  - Своя страница `404.html`, `.nojekyll` на месте, `sitemap.xml` и `robots.txt` с актуальным доменом.
- **Тема и язык — глобальные и «единым фронтом».** Хранятся в `localStorage` (`theme` = `light`/`dark`, `lang` = `ru`/`en`), читаются head-скриптом до отрисовки.
  - Модуль `settings.js` — единый источник истины: пишет в `localStorage` и слушает `storage`, поэтому переключение в любой вкладке мгновенно применяется во всех остальных открытых вкладках (без перезагрузки).
  - `theme.js` — применяет тему и обновляет иконку ☀️/🌙; `i18n.js` — переводит текст, атрибуты и заголовок страницы, создаёт кнопку языка рядом с кнопкой темы.
  - Кнопка темы и кнопка языка — единый стиль: только обводка, без цветной заливки.
- Тёмная тема по умолчанию; светлая — тёплая, солнечная (фон `#fff9e6 → #ffeaa7 → #fdcb6e`, шапки `#d4750a → #b85e0a`, текст `#5d4e37`).
- Цвета букв в комментариях автора не менялись: `#9a6a12` (заголовок) и `#6b5b3e` (текст) — одинаково в обеих темах.
- Порядок в шапках: главная — вкладки → `EN` → тема; новелла — название → «Назад» → `EN` → тема; схема — `h1` → подзаголовок → «Назад» → `EN` → тема.
- Главная страница: заголовок «Руководства для визуальных новелл в виде блок-схем» (EN — `Flowchart guide visual novels`), подзаголовок «Прохождения визуальных новелл в виде блок-схем».
- «Сделано»: 22 новеллы (включая 3 части Phoenix Wright). «Не требуют схем»: 14 новелл.
- В «Общей информации» каждого раздела: кликабельная ссылка **VNDB** (жирная), разработчик, год — на отдельных строках.
- Отдельный блок «Другие названия» на каждой странице новеллы — каждое название на своей строке.
- Все 23 схемы загружены в `assets/schemas/` и отображаются.
- **Просмотрщик блок-схем** (`schema-viewer.js`): полноэкранное окно, зум с привязкой к курсору, панорама, мини-карта с рамкой текущего участка, режимы «вписать / по ширине / по высоте / 1:1», переключение схем стрелками, полноэкранный режим, панель горячих клавиш по кнопке `?`.
- Локальные постеры в `assets/posters/` — изменения на VNDB не влияют на сайт.
- README в стиле F Works: лого `assets/logo.svg`, бейдж лицензии, русская и английская версии (`README.md` / `README.en.md`).
